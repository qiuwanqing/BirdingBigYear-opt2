# 包装鸟视频与天空 Archive 接续要求

## 目标流程

自由观察瓶子 → 点击选定的鸟所在位置 → 平滑对准对应近景 → 锁定机位 → 播放预制的鸟脱离视频 → 切换蓝天 Archive → 小黑色剪影持续游走。

## 当前已准备

- 点选不同瓶身位置可以得到不同的锁定近景。
- 工具菜单中 `DOWNLOAD` 导出当前锁定机位的模型透明 PNG，不含背景或界面。
- 已移除界面上的配置下载按钮；相机、目标点、模型姿态、曝光和尺寸仍保留在 `fixedShot`，开发辅助方法 `downloadShotConfig()` 保留用于后续接入。
- 机位对齐后自动播放 `assets/bird-release-placeholder.webm`（三秒文字占位视频），由 video 的 ended 事件直接进入天空 Archive，不使用固定计时器假装播完。
- `SKY` 可直接预览既有蓝天与剪影游走界面；没有收藏时只显示一只临时示意鸟，不写入 IndexedDB，刷新不会新增记录。
- 已接通真实 video 播放、自动结束接续、失败重试、跳过和返回机位；目前使用明确标注的占位视频，不是最终鸟动画，也没有实现无鸟标签替换。
- `BirdReleaseVideo.js` 的 `RELEASE_VIDEO` 是视频来源替换点。最终素材仍需匹配 shotId 和机位，并补上无鸟标签后才能作为正式放飞。

## 给视频制作者的素材

先确定这只鸟最终使用哪个机位，通过 DOWNLOAD 下载 PNG。后续接入时由开发端记录同一 shotId 的 JSON 机位参数，二者必须匹配。以前导出的固定 v1/v2 镜头不能代替新的点选机位。

每只鸟最终应绑定自己的固定机位和视频；不能把同一段视频套到任意点击位置。后续正式接入时，点击该鸟后需要回到制作这段视频所用的 JSON 机位再播放。

## 视频内容要求

1. 首帧严格使用配套 PNG 的构图：瓶身位置、尺寸、透视、图案和光色一致。
2. 固定镜头、固定瓶身，避免自动推拉、平移、转瓶、重构标签、添加新文字或改写周围图案。
3. 只有选定的鸟开始动作：轻微振翅 → 脱离标签 → 向预先选定的方向飞离。
4. 保留原鸟的主要辨识特征；飞远后允许简化成小黑剪影。
5. 鸟离开后，原位置是连续干净的瓶身标签，不能残留第二只静态鸟。
6. 结束时留一小段稳定的无鸟瓶身画面，便于接入天空；鸟最好已飞出画面。
7. 不生成准星、望远镜边框、扫描线、UI、字幕、logo 或水印，这些由网页处理。

## 背景与交付

- 希望交付实际含 alpha 的透明视频：透明区域仅在瓶身和鸟之外，瓶身标签本身保持不透明。请保留完整原始制作文件。
- 如果生成工具不支持 alpha，可先使用单一纯色背景生成，再去底；不要把棋盘格、黑底或白底当成已经透明。
- 文件后缀不能证明它有透明通道。收到视频后应在浅色和深色背景上检查边缘与透明度，再确认浏览器播放格式。
- 分辨率和宽高比遵循 JSON 的 frame，不能自行裁切；帧率、时长应写入交付说明。建议先用几秒短片验证接缝。
- 另交付与视频末帧一致的“无鸟标签”素材：优先为可替换的原瓶身纹理及修改区域说明；只有无鸟参考 PNG 时，仍需后续处理纹理。单张参考图不会自动修复 3D 标签。

交付包示例：

```text
bird-release/<birdId>/
  <shotId>-...-transparent.png   # 网页导出的首帧
  <shotId>-config.json          # 网页导出的机位
  release.<format>             # 审核过的透明视频；播放格式待验证
  bottle-no-bird-reference.png  # 无鸟末帧参考
  bottle-no-bird-texture.*      # 如已完成的原模型标签纹理
  delivery.txt                 # 帧率、时长、飞离方向、alpha、素材版本
```

## 后续接入位置与状态

- `BirdEncounter.capture()` / `updateFixedShot()`：点击选位、锁定。未来在匹配该视频的制作机位对齐后，进入视频加载和播放状态。
- `fixedShot`：包含本次相机快照与 shotId，用于核对素材，不能使用另一只鸟/另一机位的视频。
- 当前链路：`updateFixedShot → playReleaseVideo → video.ended → showCollection(true)`；退出时 cancel 取消播放，并通过 token/机位校验阻止旧回调误跳转。
- 视频覆盖层要与首帧的相机和宽高比一致，不允许非等比拉伸；整瓶透明视频播放时隐藏底下原来的有鸟瓶子，避免透出重复图案。
- 视频真正结束后（不是点击时）再写入收藏，按产品与鸟身份去重，然后进入 `showCollection()`；不得把用于开发的天空预览存成一次目击。
- `showCollection(true)`：当前仅供天空预览。正式接续需要先记录真实鸟资产，再调用普通 `showCollection()`。
- `SkyArchiveView.js`：实时渲染全景天空，鼠标/单指拖拽相机环视；以三维 Sprite 剪影绘制鸟，使用射线点击记录。
- `SkyBirdMotion.js` 的 `skyBirdWorldMotion()`：鸟在三维世界坐标中绕行、升降、靠近远离，出视野后仍继续运动。`BirdAnimation` 只保留旧起飞路径，不再作为 Archive 的二维显示层。
- 返回模型前应用无鸟纹理；没有无鸟纹理时，不应宣称“离开后的瓶身状态”已经完成。
- 退出、切换机位、窗口尺寸变化、播放失败及重复点击都应测试；视频期间锁定操作，退出时停止并清理播放资源。

## 收藏待办

既有收藏仍会从 IndexedDB 恢复。本轮新增记录页的 DELETE THIS BIRD 和天空菜单的 CLEAR SKY ARCHIVE，实际删除已保存记录前会确认；清空也会移除临时预览鸟。没有自动删除用户已有记录。正式视频接入仍需按 birdId 去重；占位播放不会创建永久收藏。
